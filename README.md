# Sprint_6 - тестирование сервиса Яндекс Самокат
## В папке locators находятся три файла с локаторами для BasePage, ManePage и OrderPage
## В файле urls указаны урлы, главной страница Яндекс Самоката, страница оформления заказа и главной страницы Яндекса(дзен)
## В папке pages находятся три файла в которых описаны методы для BasePage, ManePage и OrderPage
## В файле test_main_page созданы тесты:
### test_click_on_question - проверяет что при клике на каждый вопрос в блоке Вопросы о важном, открывается корректный ответ
### test_click_yandex_logo - проверяет что при клике на логотип Яндекса, в новом окне открывается главная страница Яндекса(дзен)
## В файле test_order_page созданы тесты:
### test_successful_order - проверяется оформление заказа с использованием двух наборов корректных данных и с переходом на страницу заказа через разные кнопки Заказать
### test_click_scooter_logo - проверяет что при клике на логотип Самоката, происходит переход на главную страницу Яндекс Самоката
